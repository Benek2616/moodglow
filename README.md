# ✨ MoodGlow

Piękny i prosty tracker nastroju oraz energii.

## Co potrafi?

- Szybki wybór nastroju (5 poziomów)
- Poziom energii
- Krótka notatka do dnia
- Siatka ostatnich 28 dni z kolorami i emoji
- Automatyczne podsumowanie (średnia, najczęstszy stan, insighty)
- Wszystko zapisuje się lokalnie w przeglądarce
